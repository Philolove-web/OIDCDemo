WHY IT WORKS

单点登录背后的三个关键动作

01

授权码 + PKCE

浏览器只拿到一次性授权码，并用 code_verifier 证明自己是发起方；令牌从不经过前端重定向 URL。

02

ID Token 证明“你是谁”

Keycloak 签名的 JWT 包含 sub、iss、aud、nonce、exp，登录门户逐项校验。

03

Access Token 证明“你能访问什么”

系统 1 / 2 通过 JWKS 公钥本地验签，并检查 aud 与角色；全程无需回调认证中心。
